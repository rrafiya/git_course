Git 与 GitHub 不是一回事

这是初学者最容易混淆的一点

Git
版本控制工具 · 装在你电脑上
  • 运行在本地的命令行程序
  • 负责记录每一次改动，生成版本快照
  • 每个提交有唯一 hash，可随时回退
  • 支持分支，可以并行开发互不干扰
  • 完全离线也能用，不需要网络
  • 由 Linus Torvalds 于 2005 年为 Linux 内核开发
≠
两者
常一起用
但完全独立
GitHub
代码托管网站 · 跑在云端
  • 一个网站服务，需要用浏览器访问
  • 为 Git 仓库提供云端存储与备份
  • 协作功能：Pull Request、Issue、代码审查
  • GitHub Pages 可直接把网页部署上线
  • 可视化查看提交历史、diff、贡献图
  • 同类产品还有 GitLab、Gitee、Bitbucket
一句话记住：Git 是工具，GitHub 是网站。 你可以只用 Git 不用 GitHub（版本照样记录）， 也可以把 Git 仓库传到 GitLab 而不是 GitHub。
本案例里 git init / git add / git commit 用的是 Git； 而 git push 的目标、以及你在浏览器里看到的仓库页面，是 GitHub。
