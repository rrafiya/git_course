Git 的三个区域 —— 文件是如何一步步被记录的

理解这张图，就理解了 Git 的核心

① 工作区
Working Directory
  • 你能直接编辑的文件
  • index.html、README.md …
  • 改动后 Git 会标记为「已修改」
git add
② 暂存区
Staging Area / index
  • 「这次要提交什么」的清单
  • 可以只挑部分文件提交
  • 提交前还能反悔（git restore）
git commit
③ 本地仓库
Local Repository (.git)
  • 每次提交生成一个版本快照
  • 每个提交有唯一 hash
  • 可随时回退到任意版本
git push
④ 远程仓库
Remote (GitHub)
  • 代码托管在云端
  • 团队协作、备份、分享
  • 可部署上线（GitHub Pages）
git add = 挑要提交的改动
git commit = 拍一张快照存到本地
git push = 把本地快照同步到云端
